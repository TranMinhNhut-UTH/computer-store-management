# Computer Store Management

Website quản lý bán hàng và kho linh kiện & phụ kiện máy tính.

## Giới thiệu

Dự án được xây dựng nhằm hỗ trợ quản lý hoạt động bán hàng và kho của cửa hàng kinh doanh linh kiện, phụ kiện máy tính.

Hệ thống dự kiến hỗ trợ các nghiệp vụ chính như quản lý sản phẩm, nhập hàng, tồn kho, bán hàng, khách hàng, nhà cung cấp và thống kê báo cáo.

## Trạng thái dự án

Dự án đang trong giai đoạn phân tích yêu cầu và thiết kế hệ thống.

## Công nghệ dự kiến

* Backend: C# / ASP.NET Core
* Frontend: React / TypeScript
* Database: SQL Server
* ORM: Entity Framework Core
* Version Control: Git / GitHub

## Tài liệu

Các tài liệu phân tích và thiết kế sẽ được bổ sung trong quá trình phát triển:

* Phân tích yêu cầu
* Use Case
* Thiết kế cơ sở dữ liệu
* Thiết kế giao diện website
* Tài liệu API
* Kiểm thử
